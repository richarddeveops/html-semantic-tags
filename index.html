Semantic HTML

Semantic elements describe the purpose of the content they contain.

What I learned View assignment

Common semantic elements

  • <header> introduces a page or section.
  • <nav> groups important navigation links.
  • <main> contains the page's primary content.
  • <section> groups content around a topic.
  • <article> holds a self-contained item.
  • <aside> holds related, secondary content.
  • <footer> contains closing or page information.
